Order Service (:8007)
API ENDPOINTS
POST /api/orders/create_from_cart/
GET /api/orders/by_customer/
GET /api/orders/{id}/
POST /api/orders/{id}/cancel/
▼
VIEWS + SAGA ORCHESTRATOR
OrderViewSet.create_from_cart()
1. Fetch cart từ cart-service
2. Fetch giá từng sách từ book-service
3. Tạo Order (status=pending)
4. Publish "order.saga.start" → RabbitMQ
5. Trả về 202 Accepted ngay lập tức
run_saga_worker (RabbitMQ consumer)
RPC payment.reserve → RPC shipping.reserve
Thất bại → RPC payment.compensate → cancelled
Thành công → confirmed → clear cart → update stock
▼
MODELS
Order
customer_id, total_amount, status
payment_method, shipping_method, shipping_address
payment_id, shipping_id | FK (lưu sau saga)
OrderItem
order | FK(Order)   book_id   quantity   price
▼
postgres-order
→ Cart Service → Book Service ⇄ RabbitMQ Saga

AI Recommender Service (:8011)
API ENDPOINTS
GET /api/recommendations/?customer_id=X&top_n=5
▼
VIEWS — Collaborative Filtering
RecommendView
1. Fetch all_ratings từ comment-rate-service
2. Xây ma trận user-item {user_id: {book_id: rating}}
3. Tính similarity với các user khác (cosine-like)
4. Dự đoán rating cho sách chưa đọc → top N
5. Enrich từng sách từ book-service
_recommend_popular() — Fallback
Chưa có rating → trả sách có avg rating cao nhất
▼
postgres-recommender
→ Comment Service (all_ratings) → Book Service (enrich)
